# 1. What we mean by generative AI

The main point of the video (4 min): most AI in the world is not generative. Spam filters, recommendation systems, and fraud detection are examples of AI that is not generative. This course focuses on the kind that is: transformer-based text models that produce new content, one token at a time.

# The two kinds, side by side
	Generative AI 	                   Classification and prediction AI
**What it does**            	         Produces new content	Sorts, ranks, or labels existing content
**Examples**                 	        Chatbot answers, writing, translation of new text	Spam filters, recommendation systems, fraud detection
**Simple question it answers**    	"What should I write next?"	"Which bucket does this belong in?"

**Analogy** (my own): a sorting machine at a post office (classification) vs. a writer (generative). One puts existing letters in the right box. The other writes a new letter.

# 3. Key takeaways (from the lesson)
Generative AI produces new content rather than classifying existing content.
AI is not uniformly capable, and not uniformly unreliable. It is strong and weak along four predictable axes: **Next Token Prediction, Knowledge, Working Memory, and Steerability**.
Each property is a continuum. The same mechanism produces both the capability and the limitation.
Calibrated trust means finding where my specific task sits on the continuum, instead of trusting or distrusting AI wholesale.

In simple words (my own)
Not "AI is great" or "AI is bad." It depends on which property my task leans on and how far along the scale it is.
Same trait, two faces. Example (my own, from earlier notes): predicting the next word is why Claude writes smoothly (capability) and why it can state something false with confidence (limitation).
Calibrated trust = like knowing which friend to ask about what: good at cooking tips, not at car repairs. I trust the right amount for the right job.

What is it paying attention to?	Working Memory
How much am I in control?	Steerability

# Link to my goals
Everyday use: before relying on an AI answer, ask: which property does this task lean on? That tells me how much to trust it.
AI Security (later):
"Calibrated trust" is basically risk assessment: not "is AI safe?" but "how safe is this use, and why?"
Different AI systems have different risks. A spam filter (classification) can be fooled by crafted inputs, and a generative model can be steered by hidden instructions (prompt injection). Knowing which kind I'm dealing with tells me which attacks to expect.
"The same mechanism produces both the capability and the limitation" is a core security idea: the features attackers abuse are often the same features that make the system useful.
